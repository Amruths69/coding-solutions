## Solution

**Language:** Java  
**Runtime:** N/A

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int one = scanner.nextInt();
        int two = scanner.nextInt();
        System.out.println(one / two);
    }
}
```
